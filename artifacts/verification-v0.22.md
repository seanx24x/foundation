# Foundation 0.22 — source investigations

**Installed and running in the normal Orbit profile.** Ask about relationships prepares a bounded saved-source investigation in the right-hand Assistant. Review the selected file and the exact relationship evidence, edit the question, then explicitly Send. Preparation is local. The historical shared result remains immutable; an unsent result requires explicit Refresh after restart.

## Results

- **221 project tests and 723 desktop tests pass**, with no failures or skips. Both TypeScript targets, JavaScript syntax and whitespace checks pass.
- Strict result validation bounds findings and bytes, rejects forged or mismatched descriptors, and preserves source revisions. The complete safely read inventory is checked locally before sharing and before completion. New, deleted, changed, ignored or unreadable contributors invalidate the result. Affected drafts block sharing; unrelated drafts remain untouched.
- OpenAI, Anthropic and compatible text protocols pass with the same disclosed result. The model receives the question, one selected source file and the bounded relationship envelope. Related file contents, filename-only candidates, the complete inventory, environment, prior output and unrelated history are excluded. Paths and labels inside the findings are disclosed. Request summaries are sanitized; the separately selected source is shared exactly as shown.
- Provider-native tool calls remain disabled. An investigation cannot run a project command, edit source or automatically continue the model. Truncated or interrupted replies cannot be marked complete. Cancellation and owner/source changes retain any partial response without granting new authority.
- The new packaged workflow passes across two native processes with exactly two explicit loopback Ask calls. Preparation sends nothing and retains the typed question. The completed result and a second unsent investigation restore without requests. Send stays blocked until Refresh. Changing a related saved API file retires its old call from the new evidence; the second explicit Send uses that new result, while the first history entry stays unchanged. Fixture source was restored exactly; the unrelated unsaved draft remained intact.
- Nine existing packaged regressions also pass: Relationships, restart, 17 native editor checks, request revision, staged-group refinement, AI check recommendations, saved check plans, isolated execution and grouped Apply/Undo. These verify compatibility across conversation schema7; they do not establish new model-tool capabilities. One final restart rerun timed out after a source-checkbox key produced no observed selection, before persistence or restart. The test driver now verifies stable checkbox identity, value and focus before one activation, with no retry after dispatch. Its subsequent two-process check passed with no provider request. Hydration timing is consistent with the failure but was not conclusively established; production behavior was unchanged.
