## Verified workflow

One explicit **Generate alternatives** request returned two immutable named candidates against one saved source baseline and frozen feature/screen/scenario. Native controls reviewed each two-file candidate, prepared separate source copies, ran the same registered recipe under the same requested conditions, and retained four independent observations, requests and PNG captures. The original source stayed unchanged until an explicit retained-result adoption and **Apply all**. **Undo all** restored it exactly and preserved the unrelated native draft.

The second process restored the original candidate artifact, names, selected comparison, checkpoint, unsent design brief, chosen scenario and draft. Restoration sent no request, started no runtime, staged no candidate and loaded no images automatically. Dark and light candidate/comparison captures were inspected. Narrow layout and keyboard ownership are covered by renderer tests.

The immutable artifact digest is cached only for display across streamed publications. Request and Review still perform canonical validation. Held keyboard activation retires when the exact generation scope changes. Issue navigation also refuses changed or unavailable attached evidence before offering it as the original observation.

## Boundaries

This increment covers maintained web scenarios, two candidates and two-to-eight existing application files per candidate, bounded to 64 KiB source per side. New files, arbitrary autonomous exploration, automatic ranking, direct candidate application, partial acceptance, candidate refinement and standalone candidate checks are outside scope. Each generated candidate receives one source-review checkpoint; later inspection uses that checkpoint or its retained comparison.

Compilation, observed interaction, captures and visual assessment remain separate. Records explicitly retain Compilation **Not recorded**, Visual assessment **Not assessed**, and Source to pixels **Unverified**. The provider is a deterministic, credential-free loopback fixture; remote provider quality is not established. Laptop and physical keyboard-to-display acceptance remain paused at the user's request; broad M0/M1 release gates remain open.
