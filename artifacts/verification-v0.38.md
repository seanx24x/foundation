## Evidence and boundaries

The final packaged run used `/private/tmp/foundation-038-candidate-1X0bEA/Foundation.app` with disposable profile `/private/tmp/foundation-visual-alternatives-smoke-pmBWb3` and the maintained replay-web fixture. Its copied dependency tree, small token declaration and token-preview component are disclosed setup. The baseline and proposed side share one frozen saved project snapshot; the proposal changes only the reviewed CSS token. Separate session, document, full source hash, request, replay and capture bindings were checked. The two saved PNGs differ and restore through their owning evidence stores.

Compilation is Not recorded, visual assessment is Not assessed, and source-to-pixels provenance is Unverified. Requested width, app theme and motion are recorded separately from measured viewport and browser preferences. Native scaling may round the measured CSS viewport by at most one pixel. Capture browser color/motion preferences must match the replay's measured preferences; they need not equal the app-requested theme/motion. Both requested and observed values remain in the evidence. Shared recipe and requested conditions do not establish identical backend data, browser storage or animation timing. AI remains disconnected. Trusted CDP input is automated native acceptance, not physical keyboard/display or representative-user acceptance.

The macOS process policy permits writes only inside each owned copy, loopback networking and execution of the shipped Node runtime plus the copied esbuild helper. Tests reject original writes, inherited-child writes, hard-link and symlink escapes, foreign execution and external networking. The environment does not inherit provider secrets. Local file reads and other localhost services remain reachable: this is not a confidentiality boundary or isolated backend environment.

Four pairs are retained without eviction. Each copy is limited to 32,768 entries and 512 MiB; ordinary files are limited to 16 MiB, with a 32 MiB exception only for regular node_modules `.node` binaries. Full manifests are checked before and after execution and after process stop. Interrupted work never resumes automatically. Storage retry reconciles saved evidence without replaying callbacks or retaking a screenshot.
