# References and verification records

This directory contains three checked-in interactive references and historical human-readable verification summaries:

- [Design system v1](design-system-v1/index.html): the existing light/dark component and AI-artifact reference.
- [Native Assistant reference](native-ai-pane/README.md): an isolated reference harness.
- [Native workspace reference](native-workspace/README.md): a saved bundled Orbit reference.
- `verification*.md` and other Markdown records: historical scope, outcomes and limits.

Raw screenshots, logs, session/profile snapshots, large source maps and benchmark archives are retained locally and excluded from Git. Links from historical summaries to those files are local evidence references; they will not resolve in a fresh clone. The corresponding source fixtures and test harnesses are included so new runs can produce new evidence. No raw local files were removed.

These references are development specimens. They do not establish every product capability or current app conformance. M6 remains last: create and review a brand-new visual and motion system, then apply it throughout Foundation.

See the [functionality reference](../docs/functionality.md), [repository guide](../docs/repository.md), and [running checklist](../docs/product-checklist.md).
