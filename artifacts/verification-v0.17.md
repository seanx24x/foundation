# Foundation 0.17 — isolated tool checks

**Installed and running in the normal Orbit profile.** M2.09g is verified within the supported saved-source-copy workflow. A staged change group can prepare its exact proposed source outside the original project, run an explicitly selected Node test or local TypeScript no-emit check, show bounded output, and preserve its result through restart. Apply remains a separate action. All 20 installed extension payload files match the tested candidate and built source; the ad-hoc deep/strict signature passes.

## Results

- **177 project tests and 487 desktop tests pass**, without failures or skips. Both TypeScript targets and whitespace checks pass. The final focused renderer/model suite passes 47 checks.
- The packaged workflow uses one loopback mock Build request and empty credential profiles. Actual native Prepare and Run controls execute a test against both proposed after snapshots. Generated output stays in the separate copy; original files and an unrelated unsaved draft remain unchanged.
- A second process restores the exact passed result without executing it again. Actual Prepare new workspace, Run and Stop produce a new cancelled result without another provider request. The original group remains proposed and its general verification claims remain Not run.
- An actual hanging check in packaged Electron stops after 60.029 seconds. Its explicit timeout result persists, original hashes match, and no owned process remains.
- Real process tests verify blocked network, original writes, child processes, external signals and hard-link escapes. TypeScript checks exercise the copied compiler with both passing source and actual diagnostics. Local read access remains available and explicitly disclosed.
- Host/session checks cover changed or dirty source, stale messages, trust/project/view ownership, storage failures, history limits, interruption, malformed records, copied-source tampering, literal option-like test paths and bounded output. Run cannot apply source or accept renderer-supplied commands.
- All 17 native editor checks pass. Separate native layout/context restart and grouped Build/Apply/restart/Undo regressions pass. Ordinary startup leaves provider requests at zero and platform authentication dormant.

## Native acceptance and preservation

The populated disposable execution fixture was reopened with the mock provider removed and test harness disabled. Its cancelled current run, preserved earlier passed result, actual command output and snapshot details were inspected in Foundation Dark and Light. Visual inspection found a duplicated Stop explanation; the final renderer shows it once while retaining distinct warnings and historical reasons. The full desktop suite and packaged execution workflow passed again after that presentation-only fix.

The normal app was quit gracefully, refreshed and relaunched. Understand and ProfileForm retain their editor groups, SaveButton remains unsaved, and the Profile saving feature and right-hand Assistant are restored. Ask remains selected with no task brief or source included; AI is disconnected. All eight saved Orbit files and the original 727-byte unsaved backup match the pre-work hashes after installed native inspection. No Orbit source was saved or discarded. Nothing was published to Tailscale.
