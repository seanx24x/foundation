# Public source publication

2 November 2026 · Foundation 0.47 source preview

## Scope

The repository owner explicitly authorized public source publication under the selected Foundation Source Inspection License 1.0. The public address is [seanx24x/foundation](https://github.com/seanx24x/foundation).

The public repository begins with a fresh source snapshot. Earlier development history is retained in a separate private development repository; it is not pushed here. This preserves the history without exposing the earlier MIT-labelled Foundation extension revision. The snapshot does not revoke any valid prior grant, change third-party terms, establish ownership, or represent completed legal review.

Included: Foundation source, maintained sample projects, fixtures, tests, product/workflow documentation, standalone references, readable historical summaries, the source-inspection license and scoped third-party notices. The cover illustration is original branding derived from Foundation's existing app mark, not a screenshot or a preview of the future M6 design system.

Excluded: downloaded upstream/toolchain/dependency trees, generated app bundles, credentials, project session storage, raw captures/reports/logs, native profiles, editor backups and unsaved drafts. Bundled Orbit source is sample content. Historical summary links to excluded evidence remain local references and are explained in [artifacts/README.md](../artifacts/README.md).

## Publication checks

- Reviewed the tracked current source snapshot for credential/private-key patterns, private hostnames, local user data, unexpected binaries and separate-license boundaries. No credential or private network-address match was found in that review; pattern scanning is not a guarantee of absence.
- Retained full source terms, third-party notices, versioned dependency notice hashes and existing file-level MIT declarations.
- Checked the README's factual claims against the functionality guide and running checklist.
- Rendered the README at desktop and narrow widths in light/dark modes; checked cover selection, image loading and page overflow.
- Validated the README/document links and Git whitespace; confirmed the public repository has its own snapshot history and the development repository remains private.

No application code changed for publication, and no new native acceptance or paid-provider acceptance is claimed. The previously recorded build/test results retain their original scope. No installed app was replaced or launched for this work.

## Publication is separate from distribution

This is source inspection access, not a general app download, binary license, open-source release or legal certification. The [commercial licensing review](commercial-licensing.md) retains the unresolved ownership/legal, binary dependency, notice-completeness and customer-term work. Publishing source does not close those gates.

## Keeping the repositories separate

Development continues in the private checkout and repository. To publish another snapshot, review the exact current source and notices, export tracked files into a separate checkout, and commit that snapshot onto the public repository's own history. Never mirror private refs, push private development branches, or add private commits as ancestors of a public commit. Maintain the existing public commit history when updating snapshots; avoid force-pushing.

The public repository contains the ongoing product checklist. Internal operational history and raw acceptance artifacts remain private/local. This separation changes neither the roadmap nor the final sequence: create and review a new visual/motion system, then apply it throughout the finished app.
