## Rules for this pass

1. One clear identity per selected source, one primary action per decision, one stable home for each control.
2. Central activities are Understand, Refine and Review; editing remains native. Assistant is a persistent side surface, not a competing activity. The broader four-activity product model still includes native Build/editing.
3. Put the current result and next useful action first. Move explanatory guidance and technical identity to relevant disclosures or help, not repeated paragraphs.
4. A blocked action must explain its reason next to the action even when details are collapsed. Never hide stale source, dirty selected drafts, unavailable history or broad edit scope behind a closed disclosure.
5. Retain provenance, freshness, source revision, shared scope, original context and independent verification outcomes. Condense their presentation, not their meaning.
6. Keep source changes, preview experiments, historical observations and AI interpretation distinct. A configured provider is not a tested connection. Preview compilation is not the project build or successful interaction.
7. Changes to copy and layout must preserve focus, source selection, composer drafts, history, partial responses, canvas identity, token experiments and guarded Apply/Undo.

## Normal, empty, loading and recovery map

| Surface | Normal | Empty / unavailable | Loading | Blocked / failed / recovery |
| --- | --- | --- | --- | --- |
| Project / source | Selected source and direct relationships | No folder → Open project; no selected supported file → Open in editor; unsupported analysis → explicit limit | Connecting or source refresh with editing still usable | Trust required → Manage trust; read/index failure → refresh/open affected source; retain unsaved buffer |
| Understand | Dependencies, consumers, outline and static request references | Zero imports/consumers/fetch declarations is a scoped result, not missing instrumentation | Local refresh | Dirty source labels saved revision; unknown source stays unknown; never promote static declaration to observed request |
| Refine preview | Saved-source preview with independent compile/render status | No entry/unsupported module/no mapping; primary start/source action | Building preview, then waiting for frame | Build error → inspect error and entry; stale → Rebuild; dirty → explain saved-source preview; disconnected frame does not become verified |
| Inspector / tokens | Selected element and shared CSS declaration | Select element; no explicit mapping; no CSS properties | Measurements may update without stealing selection/focus | Invalid value → inline syntax guidance; unmatched selector → explicit skipped experiment; dirty/stale → source proposal blocked; Reset experiments preserves source |
| Assistant | Conversation, selected sources, composer, result | New conversation; disconnected provider; no selected source | Preparing request, responding, saving locally, stopping | Provider/context/storage blocker visible at Send; source draft resolved in native editor; Stop preserves partial; retry prepares a new request without auto-dispatch |
| History | Recent/archived list and local save state | No conversations; unreadable/unknown schema kept intact | Saving/loading/action pending | Retry saving vs Retry loading; archived → Restore; capacity preserves previous history; no silent eviction |
| Proposal / diff | Proposed exact single-file change; Apply or read-only historical inspection | No proposal; snapshot unavailable | Proposal preparation | Changed source/draft/foreign context → block Apply; superseded artifact → read-only; Undo conflict → inspect native diff, preserve newer edits |
| Verification | Compilation / interaction / visual outcomes per revision | Not run / unavailable / no attached run | Existing preview build only; no invented test runner | Failed/stale evidence remains explicit; historic session/time stays inspectable; preview-rendered does not mean tests passed |
| Review | Current change, saved source changes, native diff/Git handoff | No Foundation changes; Git may still contain changes | Source refresh | Conflicting saved change → compare current source; discarded checkpoint does not revert applied source |
| Provider setup | Configured endpoint/model; destination shown before Send | Missing configuration → Set up AI | Three deliberate input steps | Cancel leaves config flow unchanged; invalid URL/model/key actionable; no source sent during setup; connection checked on actual request |
| Support / diagnostics | Standard editor/search/Git/terminal available | Unsupported instrumentation stays visible | Startup phase timing | Separate macOS/native access and trust failures from AI connectivity; diagnostic output supplies technical context without secret data |
